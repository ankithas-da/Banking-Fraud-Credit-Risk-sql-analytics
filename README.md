# Banking-Fraud-Credit-Risk-sql-analytics
MySQL 8.0 banking analytics on synthetic card data: fraud detection, credit risk, collections, transaction monitoring and portfolio KPIs. 100 SQL questions, data-quality checks, and Power BI and Tableau dashboard specs built on the same views. Covers 60 months (Oct 2021 to Sep 2026) with 150k transactions and 327k payments. Not Barclays data.
